# 分支切换与新建(sw / bc)

## 功能说明

- `branch-switch (sw)`:交互式切换分支。列出本地 + 远程分支单选(支持 `/` 过滤);远程分支自动创建同名本地跟踪分支;脏工作区先询问处理方式。
- `branch-create (bc)`:交互式新建分支并切换。名称表单层校验 git refname 合法性;基点可选当前 HEAD / 本地分支 / 远程引用;可选推送并设置上游跟踪。

## 设计理念

### 问题

原生操作步骤繁琐且易错:
- ❌ `git switch` 需要记住分支名,远程分支还要理解 `--track` / DWIM 行为
- ❌ 脏工作区切换可能因文件冲突直接失败,报错晦涩
- ❌ 新建分支 + 推送 + 设 upstream 是三条命令(`checkout -b` / `push -u`)
- ❌ 分支名非法字符(空格、`..` 等)只有 git 层面的英文报错

### 优化方案

- ✅ **可视化选择** - 本地在前、远程在后(标注 `(local)`/`(remote)`),同名去重
- ✅ **远程即切** - 选择远程分支自动 `--track` 创建本地跟踪分支
- ✅ **脏区三选** - 携带修改(git 默认语义)/ 自动 stash 切换后 pop / 取消
- ✅ **冲突安全** - stash pop 冲突时 git 自动保留条目,明确提示手动 `git stash pop`
- ✅ **名称校验前置** - 表单层拦截空格、`..`、`~ ^ : ? * [ \`、`.lock` 结尾等非法格式
- ✅ **一键 upstream** - 新建后确认推送即并行推送 `-u` 到所选远程

## 测试

真实 git 仓库集成回归(`/tmp` 临时仓库,注入式菜单驱动交互层):

- 名称校验:合法/非法字符表驱动全量断言
- 列表规则:排除当前分支、排除 HEAD 引用、同名远程去重、远程独有项保留
- 本地切换:分支变更 + 内容跟随
- 远程切换:本地跟踪分支自动创建,`@{u}` = origin/<name>
- 自动 stash 往返:修改跟随到新分支,stash 清空
- stash 冲突保留:pop 冲突时条目保留 + 工作区含冲突标记 + 切换视为成功
- 流程注入:携带/取消/干净仓库跳过脏区询问;创建流程含推送 upstream(同步执行器替换并行进度模型,规避测试沙箱 TTY)

## 注意事项

- 兼容性:统一使用 `git checkout` 家族命令(switch 需 2.23+,项目承诺 Git 2.0+)
- `switchToBranch(target, stashFirst)` 为纯执行函数,交互层仅做参数收集,保证可测试性
