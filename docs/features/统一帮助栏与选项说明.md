# 统一帮助栏与选项单行说明

## 功能说明

所有交互界面底部增加统一快捷键帮助栏——单行、紧凑,极小终端(< 6 行)自动隐藏,不挤占内容。同时为 reset 等命令的选项增加**单行内嵌说明**(名称亮 + 说明灰,同一行),全程不增加纵向空间占用。

## 实现位置

- 帮助栏组件: `internal/form/helpbar.go`(`HelpKey` / `RenderHelpBar` / `AppendHelpBar` / `OptionLabel` / `HelpBarMinTermHeight` = 6)
- 表单包装模型: `internal/form/form.go`(`Form` 包装 `*huh.Form`,经 `WindowSizeMsg` 跟踪宽高,`View()` 按需追加帮助栏)
- 选项说明统一组装: `internal/form/select.go`(`NewSelectForm` 经 `selectOptionLabel` 对每个选项执行 `OptionLabel(opt.Label, opt.Description)`,`Description` 为空则纯名称,零变化;`TERM=dumb` 时剥离样式)
- 表格帮助栏: `internal/form/table_select.go` / `table_multi_select.go`(单行徽章式帮助,单选表格高度预留 1 行)
- 进度屏: `internal/command/progress_model.go`(执行中底部帮助栏,完成时保留 `ui.exiting.*` 提示)
- 选项说明数据:
  - reset 模式: `internal/gitcmd/reset.go`(`resetModeOptions`,4 项含 default)
  - merge 策略: `internal/gitcmd/merge.go`(由 "name - description" 改为 name + `Description` 分字段)
  - cherry-pick 选项: `internal/gitcmd/cherry_pick.go`
  - rebase 动作: `internal/gitcmd/rebase.go`(continue/skip/abort)
  - 语言选项: `cmd/easygit/commands/set_language.go`
  - 提交类型: `internal/gitcmd/pushAll.go`(`applyCommitTypeDescriptions`,按 `commit.type.desc.<value>` 查 i18n,查不到不显示说明——优雅降级,不改库表)

## 设计要点

### 帮助栏

- 视觉(Zinc Dark,无新颜色):键位徽章 `Background(SelectionBg) + Foreground(SelectionFg) + Bold + Padding(0,1)`,动作文本 `MutedForeground`
- 单行、键值对两空格分隔;超宽整行 `SafeTruncate`
- 终端高度 < 6 行时不渲染(`HelpBarMinTermHeight`)
- 预置键位集合:`selectHelpKeys` / `multiSelectHelpKeys` / `inputHelpKeys` / `confirmHelpKeys` / `tableSelectHelpKeys` / `progressHelpKeys`

### 高度模型(零纵向占用增加)

- 内容模型:「标题 1 + 每选项 1 行 + 帮助 1」
- 表单视图总高 = `min(选项数+2, 终端高度)`(≥6 行终端)、`min(选项数+1, 终端高度)`(<6 行)
- 表格单选:`CalculateTableHeight` 预留 1 行;表格多选保持原有 3 行结构(标题/空行/帮助),仅样式更新

### 选项单行说明

- `OptionLabel(name, desc)`:名称 Primary+Bold,说明 Muted,内嵌 ANSI 单行拼接
- 说明文案 ≤ 20 字,label 总宽控制在 60 列安全线内,防超宽折行
- **内嵌段不输出 reset**:lipgloss 段尾默认 reset 会清掉 huh 选中态 `SelectedOption` 为整行设置的背景,导致名称与说明文本失去高亮、只有内边距空格带背景(断裂)。`optionSegment` 剥离段尾 reset 序列(兼容 `\x1b[m` / `\x1b[0m` 两种编码),内嵌段仅切换前景/字重,背景从外层序列连续贯穿整行(名称 + 分隔空格 + 说明 + 内边距)
- **说明段前显式复位字重(`\x1b[22m`)**:名称段的 Bold 状态在无 reset 时持续贯穿,只切前景的说明段会被错误加粗;`ansi.SGR(ansi.AttrNormalIntensity)` 仅清字重、不清背景,说明保持常规字重灰
- **TERM=dumb 纯文本降级**:huh 在 `TERM=dumb` 时自动启用 accessible 模式,直接打印选项文本且不再包外层样式;无 reset 的内嵌序列会泄漏到后续提示行,故 `selectOptionLabel` 在 `TERM=dumb` 时剥离全部样式
- 两行式/卡片式选项渲染:否决

### 实现机制说明

huh v2 的 `ViewHook` 仅在 `Form.Run()` 内通过 `compat.ViewModel` 触发,直接 `Update()` + `View()`(渲染测试路径)不会执行——因此采用 `Form` 包装模型统一为生产与测试共用路径:包装模型嵌入 `*huh.Form`,跟踪 `WindowSizeMsg` 的宽高,`View()` 末尾按高度条件调用 `AppendHelpBar`。

## 运行流程

```
表单/表格/进度屏创建
  ↓
WindowSizeMsg 记录终端宽高
  ↓
View() 渲染内容(标题 + 每选项一行)
  ↓
高度 ≥ 6 行:末尾追加单行帮助栏;否则不渲染
```

### 手动测试

```bash
make all
./easyGit reset        # 4 种模式:default/soft/mixed/hard,单行说明 + 底部帮助栏
./easyGit merge        # 策略 4 项,name + 单行说明
./easyGit cherry-pick  # 选项 4 项带说明
./easyGit rebase       # 冲突中执行:continue/skip/abort 带说明
./easyGit push-all / push-selected  # 提交类型带说明(commit.type.desc.<value>)
./easyGit set-language # en/zh 带说明
./easyGit drop / squash / tag / branch-delete / set-push-config  # 帮助栏单行出现
```

回归检查:

1. 每个交互界面底部出现单行帮助栏,键位徽章 + 灰字动作
2. 60/80 列窄屏不折行、不溢出
3. 4 行极小终端:帮助栏隐藏,内容完整可用
4. reset 默认模式不传参数,`git reset` 与 `git reset --mixed` 行为一致

## 注意事项

1. **零纵向增加**:帮助栏仅占一行,内容模型不因说明而增加行数;两行式选项渲染被否决
2. **极小终端**:终端高度 < 6 行时所有界面隐藏帮助栏
3. **优雅降级**:提交类型说明按 `commit.type.desc.<value>` 查 i18n,查不到(如用户自定义类型)则显示纯名称
4. **不引入新主题**:沿用 Zinc Dark,不新增颜色令牌、配置项或库表结构
5. **i18n**:所有帮助栏与说明文本经 `i18n.T`,中英文键同步维护
