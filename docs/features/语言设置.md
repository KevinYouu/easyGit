# 语言设置功能

## 功能说明

easyGit 支持多语言,并提供三级优先级的语言设置机制。用户可以通过命令行参数、数据库配置或系统环境变量来控制界面语言。

## 实现位置

- 数据库存储: `internal/config/language.go:9-40`
- 优先级逻辑: `internal/i18n/i18n.go:71-109`
- 设置命令: `cmd/easygit/commands/set_language.go`
- 数据库表: `settings` 表(key='language', value='en'/'zh')

## 运行流程

### 语言优先级(从高到低)

1. **运行时参数(最高优先级)**
   - 命令行标志: `--language=zh` 或 `-l zh`
   - 临时生效,不持久化
   - 用于临时切换语言

2. **数据库配置**
   - 通过 `set-language` 命令设置
   - 持久化存储在 `~/.easyGit.db`
   - 每次启动时自动加载

3. **系统环境变量(最低优先级)**
   - 检测 `LC_ALL`, `LC_MESSAGES`, `LANG`
   - 自动识别中文环境(`zh_*`, `chinese`, `china`)
   - 默认为英文

### 启动流程

```
程序启动
  ↓
初始化数据库
  ↓
加载数据库语言设置 (优先级1)
  ↓
检测命令行参数 (优先级2,可覆盖数据库)
  ↓
如无设置则使用系统语言 (优先级3)
  ↓
更新命令描述
  ↓
执行命令
```

## 配置/API

### 设置语言命令

```bash
# 查看当前语言设置
./easyGit set-language

# 设置为中文(持久化)
./easyGit set-language zh

# 设置为英文(持久化)
./easyGit set-language en
```

### 临时使用其他语言

```bash
# 临时使用中文(不影响数据库设置)
./easyGit version --language=zh

# 临时使用英文(不影响数据库设置)
./easyGit status -l en
```

### 支持的语言代码

**中文:**
- `zh` (推荐)
- `chinese`
- `cn`
- `中文`

**英文:**
- `en` (推荐)
- `english`
- `英文`

### 数据库 API

```go
// 保存语言设置
err := config.SaveLanguage("zh")

// 读取语言设置
lang, err := config.GetLanguage()

// 加载数据库语言(在启动时调用)
i18n.LoadLanguageFromDB(dbLang)

// 运行时设置(临时)
i18n.SetLanguage(i18n.LangZH)

// 获取当前语言
currentLang := i18n.GetCurrentLanguage()
```

## 示例

### 场景1: 首次使用

```bash
# 首次启动,使用系统语言(假设系统是英文)
$ ./easyGit version
Version: 1.0.0

# 设置为中文
$ ./easyGit set-language zh
✅ 语言设置成功

# 再次运行,界面变为中文
$ ./easyGit version
版本: 1.0.0
```

### 场景2: 临时切换语言

```bash
# 数据库设置为中文
$ ./easyGit set-language zh
✅ 语言设置成功

# 正常使用中文
$ ./easyGit status
显示 git 状态

# 临时使用英文,不影响数据库设置
$ ./easyGit status --language=en
Show git status

# 下次启动仍然是中文
$ ./easyGit status
显示 git 状态
```

### 场景3: 查看当前设置

```bash
$ ./easyGit set-language
📝 当前语言设置
  当前激活: zh
  数据库设置: zh

可用语言:
  - en (English)
  - zh (中文)
```

### 场景4: 优先级测试

```bash
# 1. 设置数据库为中文
$ ./easyGit set-language zh

# 2. 使用命令行参数覆盖(优先级更高)
$ ./easyGit version --language=en
Version: 1.0.0  # 显示英文

# 3. 不带参数时使用数据库设置
$ ./easyGit version
版本: 1.0.0  # 显示中文
```

## 注意事项

1. **数据库位置**: 语言设置保存在 `~/.easyGit.db` 文件中

2. **优先级记忆**:
   - 命令行参数 > 数据库配置 > 系统环境
   - 临时参数不会覆盖数据库设置

3. **线程安全**:
   - 使用 `sync.RWMutex` 保护并发访问
   - 可安全在多协程中调用

4. **初始化时机**:
   - 数据库语言在 `main()` 函数最开始加载
   - 命令行参数在命令执行前解析

5. **翻译键管理**:
   - 所有翻译键定义在 `internal/i18n/zh.go` 和 `en.go`
   - 新增翻译键需要同时更新两个文件

6. **数据库迁移**:
   - 自动创建 `settings` 表
   - 无需手动迁移

## 数据库结构

### settings 表

```sql
CREATE TABLE IF NOT EXISTS settings (
    key TEXT PRIMARY KEY,
    value TEXT
);
```

**语言设置记录:**
```sql

INSERT INTO settings (key, value) VALUES ('language', 'zh');

-- 英文设置
INSERT INTO settings (key, value) VALUES ('language', 'en');
```
