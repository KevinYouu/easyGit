# 测试用例文档

## 功能说明

本文档记录 easyGit 项目的测试用例实现,包括各个模块的测试覆盖率和测试策略。

测试文件分布在各个包的 `*_test.go` 文件中:

- `internal/gitcmd/branch_test.go` - 分支操作测试
- `internal/gitcmd/merge_test.go` - 合并操作测试
- `internal/gitcmd/reset_test.go` - 重置操作测试
- `internal/gitcmd/tag_test.go` - 标签操作测试
- `internal/gitcmd/stats_test.go` - 统计功能测试
- `internal/form/form_test.go` - 表单组件测试
- `internal/config/config_test.go` - 配置管理测试
- `internal/i18n/i18n_test.go` - 国际化测试
- `internal/testutil/git_helper.go` - 测试辅助工具

## 运行测试

```bash

```




## 测试用例详解

### 1. gitcmd 包测试

#### branch_test.go

测试分支相关功能:

- `TestGetCurrentBranch` - 获取当前分支
- `TestGetCurrentBranch_NotGitRepo` - 非 Git 仓库错误处理
- `TestGetAllBranches` - 获取所有分支
- `TestGetAllBranches_EmptyRepo` - 空仓库处理
- `TestGetAllBranches_NotGitRepo` - 非 Git 仓库错误处理

**实现位置**: `internal/gitcmd/branch_test.go:11-114`

#### merge_test.go

测试合并相关功能:

- `TestGetCurrentBranch_Merge` - 合并时获取当前分支
- `TestGetLocalBranches` - 获取本地分支列表
- `TestGetLocalBranches_OnlyCurrentBranch` - 只有当前分支的情况
- `TestCheckWorkingDirectoryStatus_Clean` - 工作目录干净状态检查
- `TestMergeStrategy_DefaultValues` - 合并策略配置验证
- `TestGetRemoteBranches_NoRemote` - 无远程仓库处理

**实现位置**: `internal/gitcmd/merge_test.go:12-144`

#### reset_test.go

测试重置相关功能:

- `TestCommit_Structure` - Commit 结构体验证
- `TestGetModeDescription` - 重置模式描述
- `TestCommit_TimestampParsing` - 时间戳解析
- `TestCommit_MessageTruncation` - 提交消息截断

**实现位置**: `internal/gitcmd/reset_test.go:8-78`

### 2. form 包测试

#### form_test.go

测试表单组件的逻辑部分:

- `TestInput_Validation` - 输入验证逻辑
- `TestConfirm_DefaultValue` - 确认框默认值
- `TestInput_DefaultValue` - 输入框默认值
- `TestInput_EmptyString` - 空字符串验证
- `TestInput_ValidString` - 有效字符串验证
- `TestConfirm_BooleanValue` - 布尔值处理

**实现位置**: `internal/form/form_test.go:8-102`

**注意**: form 包的交互式组件难以进行单元测试,主要测试其数据验证逻辑。

### 3. testutil 辅助工具

提供测试辅助函数:

- `CreateTempGitRepo(t)` - 创建临时 Git 仓库
- `RunGitCommand(t, dir, args...)` - 执行 Git 命令
- `SetupTestRepo(t)` - 设置测试仓库
- `CreateTestFile(t, repoDir, filename, content)` - 创建测试文件
- `CommitFile(t, repoDir, filename, message)` - 提交文件
- `CreateBranch(t, repoDir, branchName)` - 创建分支
- `CheckoutBranch(t, repoDir, branchName)` - 切换分支
- `CreateTag(t, repoDir, tagName)` - 创建标签

**实现位置**: `internal/testutil/git_helper.go`

## 测试策略

### 单元测试原则

1. **隔离性** - 每个测试独立运行,使用临时目录
2. **可重复性** - 测试结果稳定,不依赖外部状态
3. **清晰性** - 测试名称明确表达测试意图
4. **完整性** - 覆盖正常情况和边界情况

### Git 操作测试

对于 Git 操作测试:

1. 使用 `testutil.CreateTempGitRepo()` 创建临时仓库
2. 在测试结束后自动清理临时文件
3. 配置测试用户信息避免 Git 配置依赖
4. 测试正常流程和错误处理

### 交互式组件测试

对于交互式 UI 组件(form, spinner):

1. 主要测试数据处理逻辑
2. 验证默认值和状态管理
3. UI 渲染部分通过手动测试

## 注意事项

1. **测试隔离** - 每个测试使用独立的临时 Git 仓库
2. **清理资源** - 使用 `t.TempDir()` 自动清理临时文件
3. **错误处理** - 测试同时验证成功和失败场景
4. **跨平台** - 测试代码在 Linux/macOS/Windows 上均可运行
5. **Git 版本** - 某些测试依赖 Git 2.28+ (主要是 init.defaultBranch 配置)
