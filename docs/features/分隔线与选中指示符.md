# TUI 布局优化:分隔线 + ❯ 选中指示符

## 功能说明

所有含列表的界面在「标题下方」与「帮助栏上方」各渲染一条**全宽分隔线**(上下两条框定内容区);选中指示符统一为 **`❯`**(固定显示宽 2),随光标/选中行移动,覆盖全部布局:huh Select/MultiSelect、自绘表格单选/多选、Input/Confirm 表单与进度屏。

## 实现位置

- 指示符主题: `internal/theme/theme.go`(`GetCompactTheme` / `GetCustomTheme` 的 Focused 分支设置 `SelectSelector` / `MultiSelectSelector` = `"❯"` + `PaddingRight(1)` + PrimaryColor + Bold,❯ 与选项间距由布局产生)
- 表单包装模型: `internal/form/form.go`(`Form.dividerAfterTitle` 字段,`View()` 顶部线插在标题行后、底部线插在帮助栏前;`Update` 重建包装时保留该字段)
- 列表表单接线: `internal/form/select.go` / `multiSelect.go`(`NewSelectForm` / `NewMultiSelectForm` 置 `dividerAfterTitle = true`)
- 布局公式: `internal/form/layout.go`(`indicatorColWidth = 1`、`checkboxColWidth = 3`、`formFieldHeight` 内容模型 +2 行、`CalculateColumns` 最左 1 宽指示列(多选其后为 3 宽复选框列)、`multiTableExtraLines` 3→4、`singleTableHelpLines` 1→2)
- 表格单选: `internal/form/table_select.go`(最左 1 宽指示列,光标行渲染 `❯`,`rebuildRows(cursorRow)` 随光标移动重建)
- 表格多选: `internal/form/table_multi_select.go`(指示列 + 复选框列两列分离,光标行指示列 `❯`;View 结构改「标题 + 顶部线 + 行 + 底部线 + 帮助」)
- 进度屏: `internal/command/progress_model.go`(状态行与步骤列表间空行改分隔线;执行中帮助栏前插底部线)

## 设计要点

### 分隔线

- 复用 `theme.GetHorizontalRule(width)`(BorderColor `#404040` 的 `─` 全宽线),无新颜色
- 渲染条件与帮助栏一致:终端高度 ≥ `HelpBarMinTermHeight`(6);极矮终端零开销
- Input/Confirm 同样受益(内容固定,无高度数学);进度屏完成态不渲染底部线(保留 `ui.exiting.*` 提示)

### ❯ 指示符

- `"❯"` 显示宽 1,配合 `PaddingRight(1)` 布局间距总宽 2,与 huh 原生 `"> "` 同宽 → 零布局位移,视口滚动/对齐天然保持;间距不依赖字面空格
- huh 列表:主题换字即可,huh 渲染光标槽已存在(`renderOption` 用 `styles.SelectSelector.String()`),滚动逻辑零改动
- 表格单选:新增 1 宽指示列(Compact `[1][宽-5]`、ThreeCol `[1][8][消息][12]`、Full `[1][8][消息][12][10]`),❯ 与内容间距 2 格(列右空间 + 单元格内边距,表格结构下限)
- 表格多选:指示列(2 宽)与复选框列(3 宽)分离,❯ 与 `[ ]` 间距由列填充与单元格内边距产生,光标行/非光标行 `[` 位置恒定
- 表格行静态,光标移动时 `rebuildRows(cursor)` 刷新(行数 ≤ 数十,无性能风险,无冗余 Git 调用)

### 高度模型(较上一版 +2 行)

- 表单视图总高 = `min(选项数+4, 终端高度)`(≥6 行终端:标题 1 + 顶部线 1 + 选项 n + 底部线 1 + 帮助 1)、`min(选项数+1, 终端高度)`(<6 行)
- 表格单选预留 2 行(底部线 + 帮助),表格多选预留 4 行(标题 + 顶部线 + 底部线 + 帮助)

## 测试与验证

- `make all` 全绿;渲染测试断言视图含 `❯`,主题测试断言两个主题 Selector 样式均为 `"❯ "` 且显示宽 2
- 终端尺寸矩阵 40/60/80/120/300 宽 × 6/10/24 高:分隔线位置正确、❯ 跟随光标、无折行/溢出
- 详见 [测试用例](测试用例.md)

## 风险与边界

- 无新 i18n 键(字形与样式,无文案)
- `Form.Update` 包装重建必须携带 `dividerAfterTitle`,否则窗口尺寸消息后顶部线丢失
- 极矮终端(< 6 行)无分隔线,与帮助栏既有行为一致
